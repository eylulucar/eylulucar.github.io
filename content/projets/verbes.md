## Deux apprentissages dans un projet

Réviser la conjugaison et écrire du Python peuvent faire partie du même exercice. Ce petit conjugueur est né de l’envie de pratiquer les deux et de partager le résultat avec d’autres personnes qui apprennent le français.

## Explorer le code

Le dépôt permet de lire le programme et de découvrir les verbes qu’il prend en charge. C’est un point de départ pour observer comment on représente une forme verbale dans le code et imaginer de nouveaux exercices.
