## Two subjects, one project

Revising conjugation and writing Python can be part of the same exercise. I wanted to practise both and share the result with other French learners.

## Explore the code

The repository contains the program and the verbs it supports. It offers a starting point for exploring how to represent a verb form in code and for designing new exercises.
