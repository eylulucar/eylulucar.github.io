## A little reading, regularly

Short texts make it easier to practise French. This project gathers summaries from French-language RSS feeds, including 1jour1actu, Français Authentique and TV5MONDE.

## From RSS to a reading list

The Python script collects, cleans and filters the summaries. The repository explains how it works and includes a sample reading list. It pairs French practice with an introduction to processing data in Python.
